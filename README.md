# PS4-Payload-Sender-GUI

A simple Windows GUI for sending payloads to a PlayStation 4 running a binloader server.

## What it is

PS4-Payload-Sender-GUI is a lightweight desktop app that sends payloads over to your PS4.

## Key Features

- Send multiple payloads at once with a single click
- Custom frameless clean UI.

## Requirements

- Windows
- Microsoft Edge WebView2 Runtime
- A PS4 with a binloader server enabled

## Building

Open `BinLoaderGui/BinLoaderGui.slnx` in Visual Studio and build the `BinLoaderGui` project. The WebView2 dependency is already included in the project.

## Launching

Start the executable located in the build folder.
